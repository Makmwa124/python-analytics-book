# Data Analytics with Python and Jupyter Notebook: companion files

These are the companion files for the book *Data Analytics with Python and Jupyter
Notebook* by Mathew Kariuki.

**Get the book:** [Buy it on Gumroad](https://mathewkariuki.gumroad.com/l/data-analytics-with-python).

- `notebooks/` has one executed Jupyter notebook per chapter.
- `data/` has every dataset used in the book.
- `requirements.txt` lists the Python packages the notebooks use.

## Download

Click the green **Code** button above, then **Download ZIP**. Unzip it somewhere easy
to find, such as `Documents/python-analytics-book`, keeping `data/` and `notebooks/`
side by side. Then follow Chapter 1, section "Getting the book files".

All Bean There data is synthetic and was generated for this book.
